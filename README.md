# phD

박사논문 원고와 웹 뷰어. 서버의 `index_phd.html` 은 이 저장소를 읽어 화면을 만든다.

```
toc.json         메타(제목·저자·수정일) + 장 목록(파일명·상태)
ch0*.md          장별 원고 — 여기만 고치면 웹 화면이 따라 바뀐다
phd_viewer.js    뷰어: toc.json → 각 장 → marked 조판 → KaTeX 수식 → 목차/스크롤 추적
phd_style.css    뷰어 스타일(화면 + 인쇄)
```

- 목차는 원고의 `#`(장) / `##`(절) 제목에서 자동으로 만들어진다. 별도 목차 파일을 맞출 필요가 없다.
- 앵커는 제목의 번호에서 나온다 — `제3장` → `#ch-3`, `3.2` → `#sec-3-2`.
- 수식은 `$…$`(인라인), `$$…$$`(디스플레이).
- 브랜치 미리보기: `index_phd.html?br=<branch>` — 기본은 `main`.
